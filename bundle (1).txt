# HANDOFF - IB Group Employee Portal (PHP -> React migration)

## What this is
Frontend migration of the company HR / employee self-service portal from PHP to React.
Employees sign in, see applications, announcements and notifications, and raise requests (Gate Pass so far).
Backend is a separate .NET Web API (login API is also .NET).

## Stack
React 19, JavaScript (JSX, no TypeScript), Vite 8 with React Compiler, Tailwind CSS 4 + shadcn/ui-style
components (Radix), React Router 7 (lazy pages), TanStack Query, Zustand, Axios, React Hook Form + Zod,
CASL (roles), ESLint (+ security plugin), Prettier, Husky, lint-staged, Commitlint, Vitest.

## Rules the owner set
- Font, colours and sizes must be changeable in ONE file: src/styles/theme.css (no hard-coded colours/fonts elsewhere).
- Production ready: no console errors, no source maps in production, small JS bundle (lazy routes + vendor chunks),
  browser tab never says "Vite" or "React", no default placeholders.
- Internal login-only portal, so SEO is limited to: unique title + meta description per page, one h1 per page,
  favicon, alt text, breadcrumbs, custom 404, share image, noindex. Skipped: canonical, structured data, LocalBusiness.

## Current state (all verified: lint, Prettier, 18 tests, production build, Chrome check desktop + mobile)
Done: login, dashboard (announcements, application tiles, notifications), gate pass (list, filters, create, edit, view),
404 / access denied / crash pages, landing pages for other modules, sidebar (collapsible; drawer on mobile),
top bar (notifications, profile menu), CASL role gating (Admin only for role "admin"), token refresh on 401.
Dev runs on built-in mock data (VITE_USE_MOCK=true; any employee ID + password). Mock code is removed from production builds.

## Assumptions still to confirm with the owner
1. .NET endpoints and response shapes (guessed: /auth/login -> { accessToken, refreshToken, user { employeeId, name, roles } };
   gate pass list GET /gate-passes?search&from&to&purpose&status&page&pageSize -> { items, total }).
   Only src/config/endpoints.js, src/features/auth/api/auth.schemas.js and the *Api.js files need changing.
2. Admin module visible only to role "admin" (src/lib/ability.js).
3. Production site URL (set VITE_SITE_URL so the share image URL is absolute).
4. Token storage: localStorage (current) vs sessionStorage.
5. Logo and favicon files are a simple "IB" placeholder mark - replace with the real logo.
6. Dashboard application tiles stay disabled until href is filled in src/config/applications.js.

## Next steps
Migrate remaining modules (HR, IT, Taxes, Ibigian Self Service, Admin, Corp Communication, Corporate Policies)
following the gate-pass feature as the pattern: features/<name>/{api,hooks.js,pages,components}, register the page in
src/app/router/routes.jsx, add it to src/config/modules.js, call usePageMeta('Title') and render one <h1>.

## How to run
npm install ; npm run dev ; npm run build ; npm run lint ; npm test
IIS needs public/web.config (included) so client-side routes fall back to index.html.

Binary assets are not in this bundle: public/*.png icons and og-image.png (placeholder brand images).

# IB Group Employee Portal

HR and employee self-service portal (React migration of the PHP site). Login-only, internal.

| Area         | Choice                                                                       |

## Getting started

```bash
npm install
cp .env.example .env.local     # optional; .env.development already enables mock data
npm run dev                    # http://localhost:5173
```

In development `VITE_USE_MOCK=true`, so you can sign in with any employee ID and any password

## Changing the look: one file

Everything visual lives in **`src/styles/theme.css`**:

- **Font**: change the `@import '@fontsource-variable/inter'` line and `--font-family-sans`
- **Colours**: the `--primary`, `--sidebar`, `--background`... variables in `:root`
- **Font size**: `--font-size-base` (all sizes are rem-based and scale with it)
- **Corner radius**: `--radius`
- **Sidebar / top bar size**: `--spacing-sidebar`, `--spacing-topbar`

No component hard-codes a colour, font or size. The logo is the only image asset:
replace `src/assets/ib-group-logo.svg` (or point `components/common/Logo.jsx` at a PNG), and the
files in `public/` (`favicon.svg`, `favicon-32.png`, `apple-touch-icon.png`, `icon-192.png`,
`icon-512.png`, `og-image.png`).

## Folder structure

```
src/
  app/            App root, providers, router (routes.jsx, guards.jsx)
  components/
    ui/           shadcn-style primitives (button, input, dialog, ...)
    layout/       AppShell, Sidebar, Topbar, breadcrumbs, page hero
    common/       Logo, loaders, empty state
  config/         env, site copy, modules (sidebar), applications (dashboard tiles), API endpoints
  features/       One folder per area, each self-contained
    auth/           api, store, hooks, login page
    dashboard/      announcements, application tiles
    notifications/  bell + panel
    gate-pass/      api, hooks, schemas, list + form pages
    modules/        landing page for areas not migrated yet
    errors/         404, access denied, crash page
  hooks/          shared hooks (page title, media query, debounce)
  lib/            axios client, query client, CASL abilities, date/error helpers
  stores/         Zustand UI state
  styles/         theme.css (the one place to restyle) and index.css
  test/           test setup
```

**Adding a new module/page**: add it to `config/modules.js` (sidebar and permissions pick it up),
create `features/<name>/` with `api/`, `hooks.js`, `pages/`, and register the page in
`app/router/routes.jsx` using the `page(() => import(...))` helper. Call `usePageMeta('Title')` and
render exactly one `<h1>` in each page.

Types are documented with JSDoc (see `src/features/*/types.js`), and request/response shapes are
checked at runtime with Zod.

## Connecting the .NET API

Everything backend-specific is in three places, so adjusting to the real contract is quick:

1. **`src/config/endpoints.js`**: route paths.
2. **`src/features/auth/api/auth.schemas.js`** and **`authApi.js`**: login request body and the
   response shape (`accessToken`, optional `refreshToken`, `user { employeeId, name, roles }`).
3. **`src/features/*/api/*Api.js`**: request/response shapes per feature. Gate pass list is assumed
   to be `GET /gate-passes?search&from&to&purpose&status&page&pageSize` returning `{ items, total }`.

Set `VITE_API_BASE_URL` (default `/api`). In development, set `VITE_API_PROXY_TARGET` to your API
origin and Vite will proxy `/api` to it, so no CORS setup is needed. For production, serve the portal
and API on the same origin (or enable CORS for the portal origin).

Roles come from `user.roles`. Admin is visible only to `admin`; change this in `src/lib/ability.js`.

Mock data is compiled out of production builds, and a production build with `VITE_USE_MOCK=true`
fails on purpose.

## Production

- `npm run build`, then publish `dist/`.
- The app uses clean URLs, so the server must return `index.html` for unknown paths.
  `public/web.config` already does this for IIS. For nginx:
  `location / { try_files $uri /index.html; }`
- Source maps are disabled. JavaScript is split into per-page chunks plus three cached vendor chunks.
- The site is marked `noindex` and `robots.txt` disallows all crawling because it is an internal portal.
- Set `VITE_SITE_URL` (for example `https://portal.ibgroup.com`) so the share image (`og:image`) uses an absolute URL.
- Dashboard application tiles stay disabled until you fill in `href` for each app in
  `src/config/applications.js`.

<!-- IIS: serve index.html for every client-side route (React Router) except real files and /api. -->
<configuration>
  <system.webServer>
    <rewrite>
      <rules>
        <rule name="SPA fallback" stopProcessing="true">
          <match url=".*" />
          <conditions logicalGrouping="MatchAll">
            <add input="{REQUEST_FILENAME}" matchType="IsFile" negate="true" />
            <add input="{REQUEST_FILENAME}" matchType="IsDirectory" negate="true" />
            <add input="{REQUEST_URI}" pattern="^/api/" negate="true" />
          </conditions>
          <action type="Rewrite" url="/index.html" />
        </rule>
      </rules>
    </rewrite>
    <staticContent>
      <remove fileExtension=".woff2" />
      <mimeMap fileExtension=".woff2" mimeType="font/woff2" />
      <remove fileExtension=".webmanifest" />
      <mimeMap fileExtension=".webmanifest" mimeType="application/manifest+json" />
    </staticContent>
  </system.webServer>
</configuration>

import { useEffect, useState } from 'react'

export function useDebouncedValue(value, delayMs = 300) {
  const [debounced, setDebounced] = useState(value)
  useEffect(() => {
    const timer = window.setTimeout(() => setDebounced(value), delayMs)
    return () => window.clearTimeout(timer)
  }, [value, delayMs])
  return debounced
}

import { useSyncExternalStore } from 'react'

/** Subscribes to a CSS media query, e.g. `useMediaQuery('(min-width: 1024px)')`. */
export function useMediaQuery(query) {
  return useSyncExternalStore(
    (notify) => {
      const list = window.matchMedia(query)
      list.addEventListener('change', notify)
      return () => list.removeEventListener('change', notify)
    },
    () => window.matchMedia(query).matches,
    () => false,
  )
}

===== ./src/lib/ability.js =====
import { createMongoAbility } from '@casl/ability'
import { modules } from '@/config/modules'

/** Modules that need a specific role. Everything else is open to every signed-in employee. */
const restrictedModules = {
  admin: 'admin',
}

/**
 * Builds the permission set for a signed-in user.
 * Roles come from the .NET login response (`user.roles`).
 */
export function defineAbilityFor(roles) {
  // Not signed in: no permissions at all.
  if (!roles) return createMongoAbility([])
  const userRoles = roles
  const rules = []
  if (userRoles.includes('admin')) {
    rules.push({ action: 'manage', subject: 'all' })
  } else {
    for (const { id } of modules) {
      const required = restrictedModules[id]
      if (!required || userRoles.includes(required)) {
        rules.push({ action: 'view', subject: id })
      }
    }
    rules.push(
      { action: 'create', subject: 'gate-pass' },
      { action: 'update', subject: 'gate-pass' },
    )
  }
  return createMongoAbility(rules)
}

===== ./src/lib/api-error.js =====
import axios from 'axios'

/** Normalised error thrown by every API call. */
export class ApiError extends Error {
  status
  fieldErrors
  constructor(message, status = null, fieldErrors = {}) {
    super(message)
    this.name = 'ApiError'
    this.status = status
    this.fieldErrors = fieldErrors
  }
}

function asString(value) {
  return typeof value === 'string' && value.trim() ? value : undefined
}

/** Converts any thrown value (Axios, .NET ProblemDetails, plain Error) into an ApiError. */
export function toApiError(error) {
  if (error instanceof ApiError) return error
  if (axios.isAxiosError(error)) {
    if (!error.response) {
      return new ApiError(
        error.code === 'ECONNABORTED'
          ? 'The request took too long. Please try again.'
          : 'Unable to reach the server. Check your connection and try again.',
      )
    }
    const { status, data } = error.response
    const fieldErrors = {}
    if (data && typeof data === 'object' && data.errors && typeof data.errors === 'object') {
      for (const [field, messages] of Object.entries(data.errors)) {
        if (Array.isArray(messages)) {
          fieldErrors[field] = messages.filter((m) => typeof m === 'string')
        }
      }
    }
    const message =
      asString(data?.detail) ??
      asString(data?.message) ??
      asString(data?.title) ??
      (status === 401
        ? 'Your session has expired. Please sign in again.'
        : status === 403
          ? 'You do not have permission to do that.'
          : status >= 500
            ? 'Something went wrong on our side. Please try again later.'
            : 'The request could not be completed.')
    return new ApiError(message, status, fieldErrors)
  }
  return new ApiError(error instanceof Error ? error.message : 'Something went wrong.')
}

export function getErrorMessage(error) {
  return toApiError(error).message
}

===== ./src/lib/http.js =====
import axios from 'axios'
import { endpoints } from '@/config/endpoints'
import { env } from '@/config/env'
import { useAuthStore } from '@/features/auth/store/authStore'
import { toApiError } from '@/lib/api-error'

/** Shared Axios instance for the .NET Web API. */
export const http = axios.create({
  baseURL: env.apiBaseUrl,
  timeout: 30_000,
  headers: { Accept: 'application/json' },
})
http.interceptors.request.use((config) => {
  const token = useAuthStore.getState().accessToken
  if (token) config.headers.set('Authorization', `Bearer ${token}`)
  return config
})

let refreshInFlight = null

/** Exchanges the refresh token for a new access token. Concurrent callers share one request. */
async function refreshAccessToken() {
  const { refreshToken, setTokens } = useAuthStore.getState()
  if (!refreshToken) return null
  refreshInFlight ??= axios
    .post(`${env.apiBaseUrl}${endpoints.auth.refresh}`, { refreshToken }, { timeout: 15_000 })
    .then(({ data }) => {
      setTokens(data)
      return data.accessToken
    })
    .catch(() => null)
    .finally(() => {
      refreshInFlight = null
    })
  return refreshInFlight
}
http.interceptors.response.use(
  (response) => response,
  async (error) => {
    const original = error.config
    const isAuthCall = original?.url?.startsWith(endpoints.auth.login) ?? false
    if (error.response?.status === 401 && original && !original._retried && !isAuthCall) {
      original._retried = true
      const newToken = await refreshAccessToken()
      if (newToken) {
        original.headers.set('Authorization', `Bearer ${newToken}`)
        return http(original)
      }
      // Session is no longer valid: clearing it sends the user to /login via the route guard.
      useAuthStore.getState().clear()
    }
    return Promise.reject(toApiError(error))
  },
)

===== ./src/lib/relative-time.js =====
const formatter = new Intl.RelativeTimeFormat('en', { numeric: 'auto' })

const units = [
  ['day', 86_400_000],
  ['hour', 3_600_000],
  ['minute', 60_000],
]

/** "2 hours ago", "yesterday", "just now". */
export function formatRelativeTime(iso, now = Date.now()) {
  const time = new Date(iso).getTime()
  if (Number.isNaN(time)) return ''
  const diff = time - now
  for (const [unit, ms] of units) {
    if (Math.abs(diff) >= ms) return formatter.format(Math.round(diff / ms), unit)
  }
  return 'just now'
}

===== ./src/app/router/guards.jsx =====
import { useAbility } from '@casl/react'
import { Navigate, Outlet, useLocation } from 'react-router-dom'
import { safeRedirect } from '@/features/auth/redirect'
import { selectIsAuthenticated, useAuthStore } from '@/features/auth/store/authStore'
import ForbiddenPage from '@/features/errors/pages/ForbiddenPage'

/** Only signed-in users pass. Others go to /login and come back afterwards. */
export function ProtectedRoute() {
  const isAuthenticated = useAuthStore(selectIsAuthenticated)
  const location = useLocation()
  if (!isAuthenticated) {
    return (
      <Navigate
        to="/login"
        replace
        state={{ from: `${location.pathname}${location.search}${location.hash}` }}
      />
    )
  }
  return <Outlet />
}

/** Signed-in users skip the login page and go to where they were heading (or home). */
export function GuestRoute() {
  const isAuthenticated = useAuthStore(selectIsAuthenticated)
  const location = useLocation()
  const from = location.state?.from
  return isAuthenticated ? <Navigate to={safeRedirect(from)} replace /> : <Outlet />
}

/** Shows a "no access" page unless the user may view the given module. */
export function RequireAbility({ subject }) {
  const ability = useAbility()
  return ability.can('view', subject) ? <Outlet /> : <ForbiddenPage />
}

===== ./src/features/auth/api/authApi.js =====
import { endpoints } from '@/config/endpoints'
import { ApiError } from '@/lib/api-error'
import { http } from '@/lib/http'
import { loginResponseSchema } from './auth.schemas'

export const authApi = {
  async login(values) {
    if (__USE_MOCK__) {
      const { mockLogin } = await import('./authMock')
      return mockLogin(values)
    }
    // Request body: rename keys here if the .NET API expects e.g. `userName`.
    const { data } = await http.post(endpoints.auth.login, {
      employeeId: values.employeeId,
      password: values.password,
    })
    const parsed = loginResponseSchema.safeParse(data)
    if (!parsed.success) {
      throw new ApiError('Unexpected response from the sign-in service.')
    }
    const { accessToken, refreshToken, user } = parsed.data
    return { accessToken, refreshToken, user }
  },
  /** The token is passed explicitly because the local session is cleared right after this call. */
  async logout(accessToken) {
    if (__USE_MOCK__ || !accessToken) return
    try {
      await http.post(endpoints.auth.logout, null, {
        headers: { Authorization: `Bearer ${accessToken}` },
      })
    } catch {
      // The local session is cleared regardless of whether the server call worked.
    }
  },
}

import { create } from 'zustand'
import { createJSONStorage, persist } from 'zustand/middleware'

/**
 * Signed-in session. Persisted so a page refresh keeps the user signed in.
 * To keep tokens only for the browser tab's lifetime, swap `localStorage` for `sessionStorage`.
 */
export const useAuthStore = create()(
  persist(
    (set) => ({
      user: null,
      accessToken: null,
      refreshToken: null,
      setSession: ({ user, accessToken, refreshToken }) =>
        set({ user, accessToken, refreshToken: refreshToken ?? null }),
      setTokens: ({ accessToken, refreshToken }) =>
        set((state) => ({ accessToken, refreshToken: refreshToken ?? state.refreshToken })),
      clear: () => set({ user: null, accessToken: null, refreshToken: null }),
    }),
    {
      name: 'ib-portal-auth',
      storage: createJSONStorage(() => window.localStorage),
      partialize: ({ user, accessToken, refreshToken }) => ({ user, accessToken, refreshToken }),
    },
  ),
)

    .string()
    .trim()
    .min(1, 'Enter the reason for the visit.')
    .max(500, 'Reason is too long (max 500 characters).'),
})

        .includes(search) &&

      (!params.to || date <= params.to) &&
      (!params.purpose || item.purpose === params.purpose) &&
      (!params.status || item.status === params.status)

  })

        role="group"
        aria-label="Filter notifications"
        className="grid grid-cols-3 gap-2 border-b border-border pb-4"
      >
        {filters.map((name) => {
          const count = notifications.filter((item) => matches(name, item)).length
          const selected = filter === name
          return (
            <button
              key={name}
              type="button"
              aria-pressed={selected}
              onClick={() => setFilter(name)}
              className={cn(
                'min-h-10 rounded-xl border px-2 text-sm whitespace-nowrap transition-colors',
                selected
                  ? 'border-primary bg-primary font-bold text-primary-foreground shadow-sm'
                  : 'border-input bg-card hover:bg-secondary',
              )}
            >
              {name} ({count})
            </button>
          )
        })}
      </div>

      <div>
        {isPending && (
          <div className="space-y-3 py-4">
            {[0, 1, 2].map((i) => (
              <Skeleton key={i} className="h-16" />
            ))}
          </div>
        )}
        {isError && (
          <div role="alert" className="py-6 text-center text-sm">
            <p className="text-destructive">{getErrorMessage(error)}</p>
            <button
              type="button"
              className="mt-2 font-semibold text-primary underline"
              onClick={() => void refetch()}
            >
              Try again
            </button>
          </div>
        )}
        {!isPending && !isError && visible.length === 0 && (
          <EmptyState>You&rsquo;re all caught up.</EmptyState>
        )}
        <ul>
          {visible.map((item) => {
            const Icon = notificationIcons[item.category]
            return (
              <li
                key={item.id}
                className="grid grid-cols-[2.75rem_minmax(0,1fr)] items-center gap-x-3 border-b border-border py-3.5 last:border-b-0 sm:grid-cols-[3.25rem_minmax(0,1fr)_auto]"
              >
                <span className="grid size-11 place-items-center rounded-full bg-primary-soft text-primary sm:size-[3.25rem]">
                  <Icon className="size-5 sm:size-6" aria-hidden="true" />
                </span>
                <div className="min-w-0">
                  <h3 className="font-semibold">{item.title}</h3>
                  <p className="mt-0.5 text-sm text-foreground/80">{item.message}</p>
                </div>
                <small className="col-start-2 mt-1 text-muted-foreground sm:col-start-3 sm:mt-0">
                  {formatRelativeTime(item.createdAt)}
                </small>
              </li>
            )
          })}
        </ul>
      </div>
    </Card>
  )
}
